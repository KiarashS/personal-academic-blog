A placeholder. Replace this folder with a project of your own.

This page is a plain HTML file at public/projects/example/index.html, served at /projects/example/. Nothing here goes through the site's build: no Markdown, no React, no bundling. Whatever you put in the folder is what a reader gets, which is the point — a demo with its own scripts, a rendered notebook, a D3 visualisation or a report exported from somewhere else can all live here unchanged.

Add the folder to the Projects group in src/site.config.ts and it appears in the site's navigation. An entry can just as well be a URL somewhere else.
