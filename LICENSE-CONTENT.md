# Licence for the writing

`LICENSE` covers the site's code: everything that builds and runs it, under
`src/` (except `src/content/`), `plugins/`, `scripts/` and the configuration
files. It is MIT.

The writing and figures are licensed separately, under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
(CC BY 4.0), © 2026 Kiarash Soleimanzadeh. That covers:

- the posts and pages in `src/content/`;
- the figures, data and media that go with them, in `public/posts/`,
  `public/figures/` and `public/projects/`.

Code inside a post, in a code block or a file under `public/posts/` that a post
shows, is under the MIT licence in `LICENSE`, so it can go into a project
without the attribution CC BY asks for in the text.

Not covered by either:

- a post whose `license` frontmatter names another licence, or an item whose
  caption or text names its source and licence: those terms apply instead;
- `public/publications/`: images and video for papers, which belong to whoever
  holds each paper's copyright;
- portraits and personal marks, all rights reserved: `public/avatar.jpg`,
  `public/credit.webp`, `public/favicons/`, and the logos and signatures in
  `src/content/` (`logo*.svg`, `signature*.svg`);
- the fonts in `src/styles/fonts/`, each under the licence file beside it.
